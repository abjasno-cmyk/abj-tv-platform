- V `supabase_migrations.schema_migrations` jsou **jen 3 záznamy**:
  `20260530202031_enable_rls_core_tables`, `20260531161736_pin_function_search_path`,
  `20260630164720_021_saved_noviny_articles`. Vše ostatní šlo historicky ručně

## Schéma `abj_engine` (playout engine)

8 tabulek (`program_blocks`, `sources`, `videos`, `quota_state`,
`program_cache`, `editorial_events`, `transcript_cache`, `verox_news_editions`).

- **RLS vypnuté** — Supabase advisor to hlásí jako critical.
- Reálná expozice ověřena: `anon` ani `authenticated` **nemají** USAGE na
  schématu ani žádný table grant → přes PostgREST/API se k datům nedostane
  nikdo. Riziko je tedy dnes teoretické.
- Doporučení (nízká priorita, po launchi): zapnout RLS jako belt-and-suspenders;
  engine se připojuje přes pooler jako vlastník tabulek, RLS ho neomezí.
- ProudX: druhá instance enginu dostane vlastní schéma `abj_engine_proudx`
  (env `ABJ_PG_SCHEMA`), stejná pravidla.
